# Contribution guide

To suggest a new resource, open an issue using the resource template.

Please include:

- paper/resource title
- BibTeX key
- venue and year
- official paper URL
- official code/project URL, if available
- resource type
- modality
- primary consistency relation
- coverage values for P/C, S/E, ID, V/T, N/S, and P/W
- one-sentence diagnostic use and blind spot

Coverage labels should describe the resource's relevance to the consistency claim, not the resource's overall quality.
